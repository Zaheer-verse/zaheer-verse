# About This Repository

## Purpose

This repository contains the source code and media for Zaheer's portfolio website. It is designed to present skills, projects, and contact information in a polished, animated web experience.

## What's Included

- Main React application in `app/src`
- Public assets in `app/public`
- Legacy project pages and media in `app/public/legacy`
- Build output in `app/dist`

## Project Goals

- Present projects with strong visual storytelling
- Keep legacy work accessible alongside modern UI
- Support straightforward deployment to Vercel
- Maintain repo standards for collaboration and long-term maintenance

## Audience

- Recruiters and clients reviewing portfolio work
- Collaborators helping improve content or frontend quality
- Maintainers deploying and managing updates
